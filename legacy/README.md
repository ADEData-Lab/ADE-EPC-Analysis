# Legacy modeling and archetype analysis

This directory keeps the retired scenario/pathway modeling code and archetype analysis for historical reference. These modules are no longer part of the national ADE analysis pipeline driven by `run_ade_analysis.py`, which now focuses on heating fuel, heat pumps, heat networks, demand reduction, consumer impact, and policy scenario analyses using national datasets.

The files here are preserved to document previous London-focused modeling approaches and should not be used in current workflows. They may rely on outdated inputs and are unsupported.
